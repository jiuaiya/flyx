# 更新日志

每个版本的主要变化。**升级** 一行说明除了面板以外还要不要升级节点 agent；没写的只需升级面板，见 [升级](./guide/upgrade.md)。

完整的提交记录见 [GitHub Releases](https://github.com/jiuaiya/flyx/releases)。

## 3.3.30.9

2026-10-22

- 落地页在可见时每 5 秒自动同步最新延迟和运行状态，切回页面或网络恢复后立即同步；保留搜索、节点筛选、分组折叠及批量选择，后台失败时静默重试。
- 节点重连后自动重测该节点已启用的自建落地端口，并刷新节点测试点，避免旧端口故障继续盖住恢复后的延迟；保留 UDP 协议、仅本地监听和中转白名单端口的跳过规则。
- 落地端口检测串行执行，取消的检测不再写入缓存，避免旧检测覆盖恢复结果；表单能力和订阅来源仍按原周期同步。
- **升级**：仅需升级面板前后端，节点 Agent 无需升级。已打开的旧页面需刷新一次载入新逻辑。

## 3.3.30.8

2026-10-22

## 3.3.25.4

2026-10-20

- 出站 IP 策略新增“优先 IPv4”和“优先 IPv6”：保留双栈解析，TCP 首选地址连接失败或迟迟未连通时会尝试另一类型；缺少首选类型的 DNS 记录时也会回退。
- 优先模式允许直接连接 IPv4 和 IPv6 地址，链式出站、分流和用户流量统计继续按入站独立生效。UDP 按解析结果优先选择地址；远端静默不回包不代表连接失败，不会自动重放到另一地址。
- 补充旧版 Xray UDP 数据包的解析策略，避免“仅 IPv4 / IPv6”与 UDP 实际解析不一致。
- **升级**：只需升级面板，节点 agent 无需升级；优先回退策略需要 Xray 25.6.8+ 或 sing-box 1.12+。

## 3.3.25.3

2026-10-20
